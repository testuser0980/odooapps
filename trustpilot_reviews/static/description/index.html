About This Module

Turn Customer Trust into Your Best Marketing Asset

The Trustpilot Reviews module bridges Trustpilot and your Odoo-powered website. With a single click, fetch all your verified Trustpilot reviews into Odoo's backend, automatically generate unique author avatars, display them with beautiful website snippets, and even translate them into every active language using Odoo's built-in AI engine — no third-party subscription needed.

Features

Everything You Need, Out of the Box

One-Click Review Fetch

Simply enter your Trustpilot business URL, click Fetch Trustpilot Reviews, and all your verified reviews are automatically scraped, parsed, and imported into Odoo — no API key required.

Auto-Generated Author Avatars

For every reviewer without a profile photo, the module automatically generates a personalized initials-based avatar with a unique, deterministic color — so your reviews always look polished.

AI-Powered Translation

Using Odoo's native AI engine (OLG API), translate review headlines and bodies into all active languages — either per review or in bulk via a scheduled action. Serve global visitors in their language.

Dynamic Website Snippets

Drag-and-drop ready website builder snippets (powered by Owl + Owl Carousel) let you embed a beautiful, responsive reviews carousel on any page — no coding required.

Per-Website Filtering

Assign reviews to specific Odoo websites. Running a multi-website setup? Show only the most relevant reviews on each site and manage everything from a single backend.

Drag-to-Reorder Sequence

Control exactly which reviews your visitors see first. Use the built-in sequence handle in the list view to reorder reviews by drag-and-drop — effortlessly promote your best testimonials.

How It Works

Up and Running in 3 Simple Steps

1
Configure Your URL

Go to Trustpilot Reviews → Configuration in the Odoo backend. Add your Trustpilot business page URL (e.g., trustpilot.com/review/your-company.com).

2
Fetch Your Reviews

Click the Fetch Trustpilot Reviews button. The module scrapes the structured data from your Trustpilot page, generates author avatars, and imports all reviews instantly.

3
Add the Snippet

Open the Odoo Website Builder, drag the Trustpilot Reviews snippet onto any page, and your reviews carousel is live. Customize display options via the snippet settings panel.

AI Feature

Translate Reviews Into Every Language — Automatically

Most of your customers write reviews in their native language. Now every visitor reads them in their language too. The module uses Odoo's native OLG AI API to translate review headlines and bodies into all active languages on your instance — with no external subscription or API key required.

  • ✔ Translate a single review from its form view with one button click
  • ✔ Run a scheduled action (cron) to auto-translate up to 40 reviews at a time
  • ✔ Translations stored in Odoo's standard translation layer — works with any installed language

Installation

Getting Started

1
Download & Install the Module

Download trustpilot_reviews and place it in your Odoo addons directory. Enable developer mode, then go to Apps → Update Apps List and install Trustpilot Reviews.

pip install requests beautifulsoup4 Pillow
2
Add Your Trustpilot URL

Navigate to Trustpilot Reviews → Configuration in the top menu. Create a new configuration record and enter your Trustpilot review page URL.

3
Fetch and Manage Reviews

Click Fetch Trustpilot Reviews. Your reviews will appear under Trustpilot Reviews → Reviews. Assign them to websites, reorder via drag-and-drop, or trigger AI translations per review.

4
Embed the Website Snippet

Open the Website Builder on any page. Find the Trustpilot Reviews snippet in the snippet panel, drag it onto your page, and customize via the sidebar options panel.

FAQ

Frequently Asked Questions

Do I need a Trustpilot API key?
No. The module fetches publicly available structured data (JSON-LD) directly from your Trustpilot business page. No API key, no paid Trustpilot plan required.
Will duplicate reviews be imported if I fetch again?
No. The module checks each review's unique Trustpilot ID before importing. Only new, previously unseen reviews are added on subsequent fetches.
How does the AI translation work?
Translations use Odoo's built-in OLG (Odoo Language Generation) API via IAP. Your Odoo subscription credits are used — the same engine that powers Odoo's other AI features. No third-party AI subscription is needed.
Does it support multi-website setups?
Yes. Each review can be assigned to a specific Odoo website, and the snippet can be configured to display only the reviews for the relevant site.
